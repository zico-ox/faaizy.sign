🔍 EXEO EX58P Android Printing Architecture

1. Why Web Bluetooth alone is unpredictable for EX58P:
Portable thermal printers like the EXEO EX58P (203 DPI, 58mm) primarily use Bluetooth Classic SPP (RFCOMM) on Android. Google Chrome's Web Bluetooth API (navigator.bluetooth) only connects to Bluetooth Low Energy (BLE / GATT). It cannot open Bluetooth Classic SPP sockets.

2. The 3 Supported Printing Paths:

  • Path A: Web Bluetooth (BLE) - Works directly in Chrome if your specific EX58P hardware version has BLE advertising enabled. Requires HTTPS or localhost.
  • Path B: Android Intent (RawBT / SPP) - Works instantly on any Android phone without compiling an app. Uses the standard Android Bluetooth Classic SPP profile. Clicking "PRINT BILL" passes raw ESC/POS bytes directly to the printer in ~1 second.
  • Path C: Smallest Android WebView Wrapper - A tiny 2MB custom Android app that wraps this billing web page. Injects window.AndroidPrinter.print(base64) so printing is 100% direct and silent.
